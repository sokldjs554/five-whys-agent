# 장애 조사 프로젝트를 선택한 이유

배포 직후 주문이 느려졌을 때 필요한 건 **어떤 로그가 어떤 변경을 뒷받침하는지, 어느 지점부터 추정인지** 가려내는 일이다. `five-whys-agent`에는 이미 이 질문에 답한 모델 기록, 검색이 놓친 로그, 재전송 전후의 작업 상태가 있다. 이번 확장에서는 같은 사건을 작은 환경에서 다시 실행하고, 도구 선택부터 근거 확인·판단 보류까지 살펴볼 수 있게 했다. 지원자가 직접 디버깅한 사례를 설명할 때는 저자 제출 기록이 구체적인 QuarterGuard를 함께 제시한다.

## 어떤 부분을 가져왔나

- **그대로 연결한 부분.** 시드로 재생성한 로그와 배포 이력, 보고서 조각, 기존 MCP 서버의 읽기 도구를 쓴다. 같은 로그 ID로 모델 계획과 규칙 계획을 비교할 수 있다. [시나리오 생성기](https://github.com/sokldjs554/five-whys-agent/blob/9dda870837334bc2b0cdc29a30049920028559d8/src/fivewhys/scenarios/generator.py) · [MCP 도구](https://github.com/sokldjs554/five-whys-agent/blob/9dda870837334bc2b0cdc29a30049920028559d8/src/fivewhys/mcp_server/server.py)
- **새로 만든 부분.** 그래프의 조건 분기, MCP 호출 전후 검증, 로컬 모델 계획, 작업 API와 조사 화면을 더했다. 모델이 먼저 조사할 곳을 선택해도 원문이 모이지 않으면 보고서를 보류한다. [계획·실행](../../src/fivewhys/desk/engine.py) · [증거 판정](../../src/fivewhys/desk/evidence.py) · [화면](../../desk-demo/index.html)
- **별도 증거로 둔 부분.** 기존 Docker 확장판은 팀별 접근, 비동기 콜백, Milvus와 Neo4j가 필요한 실험이다. 로컬 기본 경로는 SQLite와 어휘 해싱으로 작동한다. 의미 벡터가 필요하면 별도 MiniLM 인코더를 선택한다. 과거 확장판과 별도 포트폴리오의 성과를 새 구현의 수치로 합치지 않았다. [확장판 Compose](https://github.com/sokldjs554/five-whys-agent/blob/f8c8e20e848b568b9a1bca9a25168758323b14c2/docker-compose.yml) · [선택형 인코더 실험](embeddings.md)

## 이번에 재확인한 기존 기록

- **과거 실제 모델 조사 한 건.** 플랫폼팀·주문 장애·시드 42에서 `claude-sonnet-5-5`는 로그·배포·과거 보고서를 검색하고 두 번째 턴에 제출했다. 최종 가설은 배포 1건·로그 4건을 인용했다. 과거 보고서 검색은 0건이었고, 배포와 관측 사이 40분의 공백 때문에 인과관계 확정을 유보했다. Git 오브젝트에서 SHA256SUMS 21개 항목과 PostgreSQL 전후 덤프를 대조했다. 503 뒤 200으로 재전송할 때 결과 해시·분석 1회·모델 2회가 유지됐다. 이 재검사에서 Claude API를 새로 호출한 횟수는 0이다. [모델·도구·최종 결과](https://github.com/sokldjs554/five-whys-agent/blob/f8c8e20e848b568b9a1bca9a25168758323b14c2/docs/verification/claude/runs/e09c4226-20bf-462f-a673-c5dab75a9f7d/result.body.json) · [응답·체크섬·DB 기록](https://github.com/sokldjs554/five-whys-agent/tree/f8c8e20e848b568b9a1bca9a25168758323b14c2/docs/verification/claude/runs/e09c4226-20bf-462f-a673-c5dab75a9f7d) · [기존 Actions 실행](https://github.com/sokldjs554/five-whys-agent/actions/runs/45585656133)
- **그래프가 검색을 바꾼 범위.** 저장된 정답별 순위에서 사건별 평균 Recall@4를 다시 계산했다. 주문 DB 7문항에서는 벡터 85.7% → 그래프 결합 100%, 인증서 만료 7문항에서는 42.9% → 64.3%였다. 한 문항에 여러 정답이 있을 수 있어 문항별 재현율을 먼저 구한다. TLS 결제 캐시 경고는 두 방식 모두 놓쳤다. 단일 시드 합성 사건의 재계산이며 Milvus/Neo4j 재실행과는 구분한다. [문항별 순위](https://github.com/sokldjs554/five-whys-agent/blob/f8c8e20e848b568b9a1bca9a25168758323b14c2/docs/verification/two-case-retrieval.json) · [측정 조건](https://github.com/sokldjs554/five-whys-agent/blob/f8c8e20e848b568b9a1bca9a25168758323b14c2/docs/verification/TWO_CASE_RETRIEVAL.md)
